# Surface unread attention in the TUI

## Goal

Surface unread attention in the TUI

## Prompt

Integrate the attention engine from the prior implementation stage into Work Context's visible TUI and navigation flows. Read active workspace knowledge and inspect stage 02's result before modifying code.

Scope:
- Show a concise, color-independent attention marker and reason for affected native sessions.
- Aggregate attention from session to stage and workspace without conflating multiple records that share the same native session ID.
- Update session, stage, and workspace switchers plus the existing sidebar/modal where appropriate. Attention destinations should be easy to find and ranked ahead of ordinary background destinations while preserving the current-session priority and existing lifecycle/status ordering.
- Acknowledge attention only when the corresponding native OpenCode session is actually current or navigation to it succeeds. Opening a dialog or another session in the same workspace must not clear it.
- Ensure an attention event remains visible if an OS toast was missed, unavailable, or suppressed.
- Keep lifecycle statuses unchanged: attention is UI-local and must not make a stage completed, blocked, or otherwise alter canonical state.
- Use one shared attention source rather than separate state in each switcher. Preserve all existing switcher creation/navigation/error behavior and cleanup.

Tests:
- Session/stage/workspace marker aggregation, sorting, shared native IDs, current-session acknowledgement, failed navigation, newer-event acknowledgement races, sidebar rendering, modal rendering, and restart-restored unread state.
- Verify text-only themes and absence of color support remain usable.
- Extend existing TUI tests without depending on a real terminal host.

Completion criteria:
- The user can identify every linked session needing attention from Work Context UI and navigate to it.
- Indicators disappear only after correct acknowledgement.
- Existing switcher and sidebar tests remain green.
- Run npm test, npm run test:tui, and git diff --check; report modified files and exact behavior.


## Result

Integrated the shared attention engine into the Work Context TUI. Added color-independent [ATTN] markers and controlled reasons to the sidebar, compatibility modal, action browsers, and session/stage/workspace switchers. Aggregation counts each native OpenCode session once across linked records, preserves current-session priority, and ranks unread destinations ahead of ordinary background destinations. Successful navigation acknowledges only the observed event key; failed navigation and newer-event races preserve unread attention. Restart restoration, shared IDs, sorting, navigation races, sidebar/modal rendering, and text-only behavior are covered by tests. Modified plugin/attention.js, plugin/session-switcher.js, plugin/stage-switcher.js, plugin/stages-tui.js, plugin/work-context-modal.js, plugin/workspace-switcher.js, test/attention.test.js, and test/stages-tui.test.js. Verification passed: npm test (144 passed, 2 skipped), npm run test:tui (68 passed), npm run check:language, and git diff --check.
