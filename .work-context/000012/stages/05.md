# Route attention across projects

## Goal

Deliver attention from a background OpenCode process to the active TUI across project roots

## Prompt

Implement cross-project in-TUI attention delivery for independent OpenCode processes running under the same user.

Requirements:
- Do not depend on tmux, terminal names, or shared project roots.
- Use a dependency-free user-level channel rooted in a validated XDG runtime directory.
- Register each TUI instance with a private lease containing heartbeat and last activity. Focus and keyboard activity should identify the active instance; stale instances must not remain active indefinitely.
- Publish bounded immutable attention event files from a background process and let only the active instance display them through the public api.ui.toast API.
- Keep project-local persistent attention semantics and navigation unchanged. Cross-project delivery is a transient toast; do not attempt cross-server navigation.
- Use strict versioned payload validation, fixed private paths, atomic writes, ownership/type/size checks, TTL/cap cleanup, controlled text, and best-effort failure isolation.
- Preserve the existing Linux desktop notifier as a fallback when the global channel is unavailable.
- Add tests for channel validation, ownership, stale leases, deduplication/expiry, cleanup, keyboard activity, and two independent project roots where A publishes and active B shows the toast.
- Update README and ADR documentation, then run the full test, language, package dry-run, and diff checks.


## Result

Implemented and released cross-project attention delivery for independent OpenCode processes. Active-instance leases and an atomic runtime event channel route transient in-TUI toasts across project roots while preserving project-local attention. Linux desktop notifications now deliver in parallel and support a best-effort Open session action that navigates the originating TUI, selects a validated tmux pane/window, and raises a captured X11 terminal window when optional tools are available. Current routed sessions no longer display redundant attention indicators. Security boundaries, lifecycle cleanup, fallback behavior, documentation, and comprehensive Node, integration, and Bun TUI tests were added. The final published version is opencode-work-context 0.4.7.
