# Compact workspace status summary

## Goal

Reduce sidebar workspace metadata noise while preserving unambiguous delivery and candidate state.

## Prompt

Implement the approved compact workspace status block in the stages sidebar.

Approved presentation for the illustrated state:
`startup · Attention ✓2`
`Candidates …1`
`Delivery 8 commits · ! plan`

Required behavior:
- Remove the redundant `Workflow ·` label and render the workflow mode first.
- Append the existing attention indicator to the mode line when attention exists, using the compact form `Attention ✓N` without introducing a new attention count or changing its semantics.
- Render candidate states compactly: use `…N` for draft/pending candidates and `✓N` for ready candidates; omit zero-valued states and omit the entire Candidates line when both counts are zero.
- Keep the word `commits` in the plan-needed Delivery form so `Delivery 8` cannot be confused with environments or candidates. Render missing delivery planning as `! plan`.
- Preserve clear, deterministic representations for unavailable delivery and environment-based delivery states. Compact those forms only where their meaning remains unambiguous; do not invent opaque symbols that require a legend.
- Reuse the already proven terminal-safe symbols `✓`, `…`, and `!`. Preserve wrapping and readability in narrow sidebars.
- Apply the same formatting semantics to the Solid TUI renderer and the plain-text stages renderer so fallback output and tests do not diverge.
- Keep repository artifacts in English. Update focused renderer/TUI tests and any user-facing documentation or snapshots that describe these lines.

Completion criteria:
- The illustrated state renders exactly as the three approved lines above.
- Zero candidate counts are hidden.
- Ready and draft candidate counts remain distinguishable when both are nonzero.
- Delivery commit counts remain explicitly labeled.
- Existing attention, candidate, delivery, and narrow-width tests pass, with new focused cases covering the compact forms.


## Result

Stage completed.
