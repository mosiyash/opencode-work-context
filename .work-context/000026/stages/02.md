# Implement progressive relay investigation

## Goal

Make cross-project relay research incremental, bounded, and resumable within the same target-agent session.

## Prompt

Implement progressive investigation as the default project-agent-relay behavior. The first target-agent request must be deliberately narrow and time-bounded, returning a useful compact answer rather than attempting exhaustive project research. Define and enforce a structured response that includes the answer, confidence, unresolved gaps, and suggested follow-up questions. Allow the calling agent to issue focused follow-up questions by resuming the same target-agent session so previously discovered project context is reused. Add sensible limits for initial breadth and automatic continuation, and preserve existing safety rules around retries and user approval. Investigate the current invalid-report and idle-timeout paths shown by relay runs; improve report-format reliability and ensure long research does not remain silent until the idle timeout, using bounded intermediate progress or another minimal compatible mechanism. Update relevant documentation and tests. Keep the implementation backward-compatible only where required by existing public contracts. Completion criteria: an initial relay request produces a compact useful response within its configured budget; follow-ups reuse the same session; malformed reports and idle periods have deterministic handling; and the focused test suite passes.
