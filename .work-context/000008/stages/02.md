# Prevent automatic stage switching

## Goal

Prevent automatic stage switching

## Prompt

Investigate and change the plugin lifecycle so creating additional stages or finishing the current stage never automatically starts, resumes, or activates another stage within the same OpenCode session. Preserve the core invariant that each stage transition requires a new session started explicitly through the resume operation, while allowing multiple sessions for one stage. Review tool responses, lifecycle commands, generated instructions/prompts, and tests for any behavior that encourages the model to continue immediately in a newly created or downstream stage. Define the exact boundary between stage creation, stage completion, session closure/handoff, and explicit resume; implement the smallest correct change; add regression tests covering creation of one or several stages from an active session and completion of a stage with downstream planned stages. Ensure returned structured data may identify the next stage/action but cannot bind the current session to it or instruct the model to begin it. Update English documentation where the lifecycle contract is described. Run relevant tests and report the behavioral contract and verification results.


## Result

Removed adapter-level automatic stage startup from work_context_add_stage. Stage creation now returns planned/session_started=false/resume_required=true and never binds either associated or unassociated OpenCode sessions. Stage completion explicitly reports next_stage_started=false while retaining informational downstream prompt_review data and closing only the current stage session. Updated tool/help descriptions, canonical and local /wc command contracts, README lifecycle documentation, and regression tests for multiple additions, unassociated additions, and completion with downstream planned stages. Verification: npm test passed 96 tests with 94 passes and 2 expected TUI smoke skips; git diff --check passed. npm run check:language found only the existing active workspace title in generated .work-context projections, not changed English repository source.
