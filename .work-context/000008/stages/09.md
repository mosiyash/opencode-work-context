# Session switcher

## Goal

Session switcher

## Prompt

Design and implement a session switcher based on the existing Work Context navigation components, while treating session navigation as a distinct UX problem from stage and workspace switching. First inspect session metadata, lifecycle states, OpenCode session IDs, native session navigation, and the existing read-only session browser. Decide how to rank active and historical sessions, how to group or label sessions by workspace and stage, and whether selecting a historical session should only navigate or also change lifecycle state. Do not create, resume, hand off, or mutate a session from a read-only switch action unless the design explicitly requires a separate action. Add a discoverable command-center entry and a dedicated shortcut only if the host keymap supports it without conflicts. Define and test behavior for duplicate or missing OpenCode IDs, closed and handed-off sessions, navigation failures, and current-session highlighting. Record important design decisions in durable knowledge and run focused plus full tests.


## Result

Implemented the read-only session switcher and unified OpenCode leader navigation. The command center now supports Ctrl+Alt+W followed by W for the main Work Context window, S for stage switching, O for workspace switching, and E for session switching. Session navigation ranks current and active sessions deterministically, deduplicates native OpenCode IDs, keeps records without native IDs disabled, and never mutates lifecycle state. Added focused tests covering ranking, duplicate and missing IDs, navigation failures, current highlighting, command registration, and leader bindings. Focused TUI tests pass: 60 passed, 2 skipped.
