# Simplify work-context session titles

## Goal

Simplify work-context session titles

## Prompt

Review how work-context metadata is rendered in the sidebar header and OpenCode session list. Evaluate the proposed compact common title `000008 01/01`, removing the workspace title from the generated/common session heading because it is repeated, consumes vertical space, and makes sessions from the same workspace difficult to distinguish. Determine which text is controlled by this plugin versus OpenCode, and preserve enough information to identify workspace, stage, and session ordinal at a glance. Prefer stage-specific or user-renamed session summaries where a descriptive second line is useful; do not remove the workspace title from views where it provides unique navigation context unless the UI remains unambiguous. Implement the smallest coherent presentation change, update relevant tests and English documentation, and verify both narrow sidebar rendering and the session picker with multiple sessions in one stage and multiple stages in one workspace. Report the final display contract and any OpenCode limitations.


## Result

Implemented the approved session-title presentation. Native OpenCode session titles now render the stage title first and the optional issue reference plus workspace/stage/session coordinates and inactive state second. The optional TUI sidebar renders the workspace title as an independent block before Stages. Updated focused tests, README, and ADR 0002. Verification passed: npm test (94 passed, 2 skipped), TUI smoke (47 passed), focused suites (88 passed, 2 skipped), and git diff --check. The repository language check is blocked only by the existing Russian workspace 000008 title in structured work-context projections; those projections were not edited manually.
