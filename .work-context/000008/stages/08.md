# Workspace switcher

## Goal

Workspace switcher

## Prompt

Design and implement a workspace switcher based on the existing Work Context command center and stage switcher. First inspect the current OpenCode navigation APIs, workspace/session mappings, and stage switcher behavior. Decide how switching workspace should select an existing OpenCode session, how to handle workspaces with multiple sessions, and what to do when no OpenCode-backed session exists. Preserve lifecycle state and do not create or mutate work-context entities merely by browsing or switching. Reuse proven navigation mechanics only where they fit; workspace switching may have different filtering, selection priority, and empty-state UX. Add a discoverable command-center entry and a dedicated shortcut only if the host keymap supports it without conflicts. Define and test behavior for successful navigation, missing sessions, closed sessions, terminal workspaces, and navigation failures. Update relevant documentation or durable knowledge with decisions, and run focused plus full tests.
