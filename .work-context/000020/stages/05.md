# Integrate startup agent workflow

## Goal

Make agents consistently form and publish commit candidates instead of reconstructing stage ownership.

## Prompt

Integrate the completed startup-mode and candidate APIs into the OpenCode command contract and user workflow. When a current workspace is in startup mode, present concise policy context to the agent: shared dirty worktree and concurrent stages are expected; stages do not own files; ready work must be captured promptly into an explicit candidate; mixed-stage provenance alone is not a reason to stop; actual overlapping/stale candidate patches must stop with a concrete conflict. Keep standard mode's existing conservative behavior unchanged. Add candidate status to the appropriate read-only snapshots and show a compact pending/ready candidate summary in the sidebar only if it remains readable; do not make renderers read Git state directly. Update README, command help, examples, ADRs, and integration tests covering session association, startup policy visibility, candidate lifecycle, and standard-mode isolation. Include a realistic end-to-end temporary-repository test: candidate A is captured, unrelated B work continues, A is committed, and B remains as WIP. Run all tests, TUI/integration suites, language checks, package dry run, and working-tree/diff checks. Expected result: startup mode is an explicit, visible, documented end-to-end workflow that avoids retrospective stage attribution and safely ships ready subsets.


## Result

Integrated startup-mode policy into associated OpenCode create/resume flows while preserving standard-mode behavior. Added metadata-only pending/ready candidate summaries to read-only snapshots and compact sidebar rendering without Git access. Updated command help, README, ADR documentation, and synchronized the managed slash command. Added session-association, standard-mode isolation, snapshot/rendering, and realistic candidate A with unrelated B WIP coverage. Full Node, integration, Bun TUI, language, package dry-run, and diff checks passed.
