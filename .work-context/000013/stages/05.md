# Integrate tree view

## Goal

Make the dependency tree available in a dedicated TUI view.

## Prompt

Integrate the deterministic dependency tree renderer into an appropriate dedicated TUI surface without replacing the compact sidebar list. Follow existing OpenCode TUI plugin conventions and ensure a narrow terminal degrades safely. Add rendering and integration tests using the existing TUI test patterns. Completion criteria: users can open or view the complete dependency tree while the sidebar remains compact.


## Result

Integrated the full dependency tree into a native TUI dialog, opened with `<leader>t`, while retaining the compact sidebar dependency list. Added compact ASCII rendering and safe title truncation for narrow terminals, plus renderer, dialog, hotkey, and live TUI coverage. `npm run test:tui` passes with 77 tests.
