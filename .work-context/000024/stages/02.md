# Compact sidebar header

## Goal

Make the sidebar context block visually consistent and compact without reducing status clarity.

## Prompt

Implement the approved sidebar-header refinement and stage-detail alignment in the native OpenCode TUI.

Read the active workspace knowledge first. Work in `plugin/stages-tui.js` and focused TUI tests unless a smaller proven boundary is needed.

Required changes:
1. Render the workspace attention summary with the same muted informational treatment as workflow, candidates, and delivery; preserve its textual label and count, so it remains readable without relying on color.
2. Replace the separate attention, candidate, and delivery header rows with one compact, muted summary row when one or more signals exist. Preserve all currently available information and use clear separators; do not render an empty row.
3. Correct the visual alignment of per-stage metadata (`Tasks`, `Deps`, and `Pending`) below a stage title. It must consistently read as attached to the corresponding stage, without an unexplained horizontal offset or a blank vertical gap. Do not use fragile literal-space padding to reproduce the title columns; use layout structure that remains correct with activity/attention markers, wrapped titles, and narrow sidebars.
4. Keep the workspace title, workflow row, stage heading, current-stage emphasis, interactive behavior, refresh lifecycle, snapshot shape, and read-only boundary unchanged.
5. Preserve sensible wrapping in narrow sidebars. Do not introduce custom truncation or hide signal values.
6. Update focused renderer tests for color/tone, compact grouping, omitted-empty behavior, candidate and delivery variants, and stage-metadata alignment with wrapped titles and marker combinations.

Run the focused TUI test file and any directly affected checks. Inspect the diff and working tree without altering unrelated changes.

Expected result: the informational header uses a single restrained visual style and consumes less vertical space, while stage metadata remains visibly attached and aligned to its owning stage.


## Result

Refined the native sidebar header into one muted, wrapping summary row and structurally aligned stage metadata beneath each title. Released and verified opencode-work-context 0.10.3.
