# Проверка установки и обновления плагина

## Goal

Проверка установки и обновления плагина

## Prompt

Проверить воспроизводимость установки и обновления opencode-work-context в стороннем проекте lk2 после исправления TUI loader. Зафиксировать окружение: opencode-work-context 0.1.9, OpenCode 1.18.25, проектный loader .opencode/tui-plugins/work-context-stages.js с host runtime wrapper и включение через .opencode/tui.json. Выполнить установку/обновление через npx --yes opencode-work-context@0.1.9 init --force, проверить версии в .opencode/package.json и node_modules, убедиться, что stages отображаются после перезапуска и обновляются без перезагрузки при lifecycle-изменениях. Не редактировать вручную .work-context Markdown, JSONL, INDEX или SESSIONS projections. Зафиксировать фактические команды, результаты, ограничения и остаточные проблемы. Критерии готовности: новая версия устанавливается в проект, TUI loader загружается OpenCode, stage list виден для текущей сессии и обновляется автоматически без перезапуска OpenCode. Ожидаемый результат: подтверждённый короткий runbook обновления плагина и диагностики случаев, когда stages исчезают.
