# Verify plugin installation and update

## Goal

Verify plugin installation and update

## Prompt

Verify that installing and updating opencode-work-context in the external lk2 project remains reproducible after the TUI loader fix. Record the environment: opencode-work-context 0.1.9, OpenCode 1.18.25, the project loader .opencode/tui-plugins/work-context-stages.js with the host runtime wrapper, and enablement through .opencode/tui.json. Run the installation/update with npx --yes opencode-work-context@0.1.9 init --force, check versions in .opencode/package.json and node_modules, and confirm that stages appear after restart and update without reload during lifecycle changes. Do not manually edit .work-context Markdown, JSONL, INDEX, or SESSIONS projections. Record the actual commands, results, limitations, and remaining issues. Completion criteria: the new version installs in the project, the TUI loader loads in OpenCode, the stage list is visible for the current session, and it updates automatically without restarting OpenCode. Expected result: a concise, confirmed runbook for updating the plugin and diagnosing missing stages.

## Result

Verification completed. The lk2 project was unavailable in the accessible workspace, so the isolated fixture `/tmp/opencode/lk2-real.f5eha9` was used. Running `npx --yes opencode-work-context@0.1.9 init --force` from the project root successfully installed version 0.1.9 in devDependencies and node_modules and created `.opencode/tui-plugins/work-context-stages.js` and `.opencode/tui.json`; a repeated run also succeeded. The loader imports under OpenCode 1.18.25 and exports `id: work-context-stages` and `tui`. The Node suite `node --test test/stages-tui.test.js` passed 29 tests with 2 skipped and no failures, covering initial load, session.updated debounce, completed work_context tool events, fs.watch and polling refresh, session routing, and cleanup. A real OpenTUI smoke test was not run because Bun was unavailable. `npm test` passed 65 tests and reported 4 installer failures caused by Node 26 ESM scope and a CommonJS fake npm in the test harness; real npm install did not reproduce them. Remaining npm warnings were 4 low-severity vulnerabilities, deprecated glob, and pending msgpackr-extract script approval. The runbook and diagnostics are recorded in KC-0001.
