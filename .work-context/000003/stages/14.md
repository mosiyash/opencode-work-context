# Audit public repository language

## Goal

Audit public repository language

## Prompt

Research whether any transliterated Russian or Russian-language text remains anywhere in the public repository, including tracked `.work-context`, README, documentation, commands, source, plugins, tests, and other committed files. Distinguish genuine English from transliteration, inspect the full repository rather than relying only on a Cyrillic search, and report every finding with file paths and line numbers. Do not modify files during research. If any transliteration or Russian text remains, create a follow-up implementation stage with a detailed prompt to fix it, preserving technical identifiers, dates, statuses, event structure, and historical meaning. Completion criteria: a documented repository-wide audit, explicit pass/fail for public content, and a clear remediation plan for every finding.
