# Implement sidebar click navigation

## Goal

Implement sidebar click navigation

## Prompt

Implement mouse-driven stage navigation in the OpenCode TUI sidebar. Inspect the existing stage-switcher flow in plugin/stage-switcher.js and reuse its navigation semantics rather than duplicating lifecycle or session-creation logic. Update plugin/stages-tui.js so each visible stage row is clickable through OpenTUI mouse event support and selecting it performs the same behavior as the Ctrl+X S stage selector: open an existing selected session or create and resume a new session when eligible. Preserve safeguards for terminal stages and blocked dependencies, current attention behavior, recent-stage tracking, dialog handling, and user feedback. Add focused tests in test/stages-tui.test.js that verify rows expose mouse handlers and clicks route the selected stage through the shared switching behavior, including a failure path. Run the relevant test file and report the result. Completion criteria: clicking a sidebar stage has equivalent navigation behavior to choosing that stage in the selector, with no duplicated business rules and passing tests.


## Result

Implemented mouse-driven sidebar stage navigation through the shared stage-switcher flow. Each visible row exposes an OpenTUI mouse handler; clicks preserve session selection or creation, safeguards, attention acknowledgement, recent-stage tracking, dialog handling, and toast feedback. Added focused tests for row handlers, successful navigation, and navigation failure. Verified with npm test.
