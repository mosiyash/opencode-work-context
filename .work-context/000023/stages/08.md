# Reconcile Sidebar Attention Counts

## Goal

Make the workspace Attention header and visible stage signals use one consistent non-archived unread-session set.

## Prompt

Diagnose and fix the sidebar Attention summary mismatch where the workspace header can show more response-complete (`✓`) items than are represented by visible stage rows. Do not assume archived-stage inclusion is the only cause: reproduce and distinguish stale attention snapshots, archived transitions, duplicate/multiple sessions per stage, hidden stages, and mapping races before changing behavior.

File-level scope:
- `plugin/attention.js`: inspect `visibleSessionRecords`, refresh sequencing, workspace/stage aggregation, session deduplication, acknowledgement, persisted attention restoration, and stale mapping behavior.
- `plugin/stages-tui.js`: ensure workspace and stage summaries are computed against the same rendered snapshot or a shared filtered attention view; avoid independent evidence sets.
- `src/stages-snapshot.js` and `src/work-context-snapshot.js`: verify archived filtering and session/stage mapping contracts; change read models only if the mismatch cannot be fixed at the attention/TUI boundary.
- `plugin/work-context-modal.js`, `plugin/stage-switcher.js`, and `plugin/workspace-switcher.js`: regression-check shared attention aggregation semantics and navigation, changing them only when required for consistency.
- `test/stages-tui.test.js` and `test/attention.test.js`: add focused regressions; extend integration tests only if the bug depends on asynchronous plugin refresh/tool hooks.

Required investigation:
- Reproduce a visible stage with one response-complete signal while another unread session belongs to an archived stage.
- Reproduce archive after attention was already persisted and after the sidebar/attention controller has loaded an older snapshot.
- Reproduce two unread sessions mapped to one visible stage and define/render the expected grouped stage signal and workspace total.
- Check one OpenCode session ID referenced by multiple work-context session records, current-session exclusion, closed/abandoned sessions, missing stage records, and snapshot refresh generation races.
- Determine whether the screenshot is a persistent aggregation bug or a transient stale-render bug; fix the root cause rather than hiding the count.

Behavioral invariant:
- The workspace header count is the union of unique unread OpenCode session IDs represented by visible, non-archived stage rows in the same effective sidebar snapshot.
- Archived, stale/unmapped, duplicate, and non-navigable attention must not inflate the header.
- Multiple unread sessions on one visible stage remain countable and render as a grouped stage signal (for example `✓2`) so the row-level display reconciles with the header.
- Refresh/archive transitions update header and rows atomically from the user's perspective; no long-lived mismatch is allowed.
- Do not delete valid persisted attention merely because a stage is temporarily unavailable or a snapshot read fails. Preserve it for other navigation surfaces when appropriate, but exclude it from this sidebar aggregate until it is visibly mapped.

Completion criteria:
- A regression test fails on the original implementation and identifies the actual mismatch mechanism.
- Header and visible-row attention counts reconcile after initial load, archive/restore, async refresh, acknowledgement, and persisted-state restoration.
- Existing archived-only coverage, attention priority grouping, notifications, navigation acknowledgement, modal/switcher ordering, and current-session suppression remain correct.
- The change is minimal and does not alter candidate `ready` counts or lifecycle storage.

Focused tests:
- visible plus archived unread sessions;
- archive after persisted unread attention with stale then refreshed snapshots;
- two sessions on one visible stage and one session duplicated in metadata;
- missing/unmapped stage, closed/abandoned session, current session, and failed snapshot read;
- out-of-order concurrent refresh completion;
- workspace header grouped summary equals the sum/union represented by visible stage signals;
- no regression in `test("sidebar omits attention linked only to an archived stage")`.

Run at minimum `node --test test/attention.test.js test/stages-tui.test.js`; run `npm run test:tui` and the relevant integration suite if rendering or plugin refresh wiring changes.

Expected result: a root-cause fix with deterministic tests proving that the sidebar Attention header cannot count unread response-complete items absent from its visible stage list.
