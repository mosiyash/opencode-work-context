# Доработать визуальный формат списка stages в TUI

## Goal

Сделать stages panel похожим на Todo-блок OpenCode и удобным для чтения в узкой sidebar.


## Result

Title`, корректные узлы и переносы для узкой sidebar, theme-aware цвета current/muted stages и muted workspace status. Добавлены contract tests; npm test 33/33, git diff --check успешно.
