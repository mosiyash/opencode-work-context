# Добавить обновления, fallback и обработку ошибок

## Goal

Реализовать initial load, event-driven refresh, обработку отсутствующего workspace, ошибок storage и graceful degradation при недоступном TUI API.


## Result

Добавлены устойчивые read-only stages TUI обновления: initial snapshot load, debounce 100-250ms по session ID, refresh по session.updated с поддержкой payload-вариантов, защита от stale reads, fallback на последний успешный snapshot с non-blocking stale/error marker, empty state для отсутствующего workspace, безопасная обработка STORAGE_ERROR, идемпотентный lifecycle cleanup timers/subscriptions/slots и explicit disposer для hosts без lifecycle API. Обновлены contract tests; npm test и git diff --check прошли.
