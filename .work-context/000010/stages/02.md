# Implement explicit stage completion and reopen

## Goal

Implement explicit stage completion and reopen

## Prompt

Implement the agreed lifecycle changes in opencode-work-context. First inspect the command parser, tool definitions, core state transitions, projections, session reducer, generated command documentation, plugin guidance, and tests. Enforce that an agent must not invoke work_context_finish_stage unless the user explicitly requests the lifecycle command, except when the current workspace Planning-stage prompt contains an explicit recorded agreement permitting automatic completion; document an unambiguous, safely detectable agreement format and ensure prompt guidance carries it to all stages. Add a structured work_context_reopen_stage tool and /wc stage reopen <workspace> <stage> "reason" command. Reopen only completed stages, preserve prior result and lifecycle history, record the reason through an event or canonical stage metadata, set the stage to in_progress, and do not start a session automatically; require an explicit resume in a separate OpenCode session. Define stable errors for invalid state and active-session conflicts, and ensure reopening never starts or mutates downstream stages. Update command docs, README, any packaged skill/system guidance, help text, tool registration and test coverage. Do not edit work-context projection files directly. Run npm test, npm run check:language, and git diff --check. Report modified behavior, verification results, and any release steps not performed.


## Result

Implemented explicit user-controlled stage completion and the reversible stage reopen lifecycle. Added structured tool registration, canonical history preservation, command guidance, modal support, and regression coverage. Verification passed: npm test and git diff --check; language check passed after workspace title translation.
