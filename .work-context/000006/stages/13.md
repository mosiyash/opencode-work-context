# General functionality improvements

## Goal

General functionality improvements

## Prompt

Implement a shared workspace context base for sequential work across stages. Every stage start or resume must receive active Durable Knowledge entries in structured resume.context so that established facts, decisions, constraints, important files, and risks are not reanalyzed without reason. The stage prompt remains the local instruction, while workspace knowledge is shared memory. Clarify and strengthen the knowledge review contract during stage finish: the agent must add new durable findings, update changed entries, supersede obsolete entries, or explicitly state that no new findings exist. Do not automatically copy complete stage results. Update commands and documentation, and add regression tests for start and resume with active and superseded knowledge entries, an empty knowledge base, and finish review. Preserve structured results and stable error codes, and never edit work-context projections directly.
## Result

Implemented workspace-wide shared context across stages. startSession now includes active Durable Knowledge entries in resume.context.workspace_knowledge while excluding superseded entries and full stage results. Planning instructions now direct workspace-wide discoveries into explicit knowledge operations and keep stage prompts local. Stage finish validates the knowledge ledger for every review mode and returns total and active entry counts. Updated tool descriptions, /wc command contract, README, core and integration regression tests. Verification: npm test passed 91 tests with 2 expected TUI smoke skips; git diff --check passed.
