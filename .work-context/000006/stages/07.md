# Explicit command insertion

## Goal

Add safe user-visible preparation of canonical /wc commands without executing mutations.

## Prompt

Add explicit modal actions for details, selecting workspace/stage, and inserting canonical /wc commands into the prompt. Support examples such as /wc resume 000004 02, /wc workspace list 000004, /wc stage handoff 000004 02, and /wc stage finish 000004 02. Validate and safely escape identifiers using the existing command contract. For resume, handoff, and finish, never invoke server tools, lifecycle operations, shell commands, or LLM execution; show the exact prepared command and clearly state that the user must submit it. Use only the supported prompt insertion API if available, otherwise expose a safe documented fallback without hidden execution. Add tests proving insertion and absence of storage mutations. Completion criteria: command preparation is explicit, inspectable, canonical, and read-only until the user submits the prompt.
