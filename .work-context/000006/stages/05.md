# Read-only modal read model

## Goal

Expose all available work-context state safely without lifecycle or storage mutations.

## Prompt

Implement a structured read-only read model for the modal using existing core/storage functions and WorkContext.openExisting. Cover all available workspaces, stages, statuses, titles, descriptions, current stage, active/current session, and existing session metadata. Handle absent, empty, malformed, and concurrently changing storage with stable structured errors and no writes. Do not duplicate storage invariants, create directories, create workspaces/stages/sessions, update projections, call tools, send prompts, or invoke an LLM. Preserve the last successful snapshot on refresh failures and expose a stale indicator. Add focused unit/contract coverage for these cases, but do not run verification commands until the developer explicitly requests them. Completion criteria: read model is deterministic, safe, and independent from the server plugin; malformed or racing reads cannot crash the TUI.


## Result

Added src/work-context-snapshot.js and exported readWorkContextSnapshot from src/index.js. The read model uses WorkContext.openExisting, lists all workspaces, reads stages and reduced session metadata through core APIs, marks current workspace/stage from the supplied OpenCode session ID, filters archived stages, and returns stable structured errors with an empty snapshot. It performs no initialization, writes, projection updates, tool calls, or prompt actions. Added focused tests for absent storage and all-workspace/session metadata behavior; tests were not executed per the explicit verification restriction. Stale snapshot retention remains in the TUI controller.
